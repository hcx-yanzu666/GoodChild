## 一、项目定位

| 项目 | 内容 |
|---|---|
| 类型 | 第一人称 · 规则怪谈 · 中式家庭恐怖 · 生存解谜 |
| 引擎/平台 | UE / PC（Steam） |
| 开发方式 | 独立开发 |
| 目标 | 商业发售 + 作品集 |
| 体量 | 主线约 1.5~2 小时，含多结局约 4~5 小时 |
| 定价建议 | ¥18~28 |
| 一句话 | 你是被"好孩子"标准养大的孩子。写完作业就能安全，但想知道真相，就必须违反规则。 |
| 宣传句 | "写完作业，你才能活下去。" |

### 范围决策的演变
1. 【用户】最初设想：三天三个阶段（小学→高三→职场），每天换怪物。
2. 【建议】独立开发风险大，推荐三阶段为：小学（妈妈）→ 高三（老师+比较）→ 打工人（领导/亲戚/内化的自我），暗线是怪物都是"妈妈"的变体。
3. 【建议】但独立开发更建议**只打磨一天**，结尾留钩子暗示后续。
4. 【用户】最终方向：**做两天**，场景和怪物不变；第二天题目更难，并加 1~2 条新规则。（已确认）

## 二、背景设定

- **主角**：典型中式教育下长大的孩子，每天唯一任务是写完作业。
- **场所**：老式住宅。卧室是"伪安全屋"；外出区域有客厅、厨房、父母房、储物间、外公房间（始终上锁）。
- **压迫者**：妈妈。表面温柔、笑容标准，但有不对劲的地方。
- **暗线**：爸爸早已不在家；"妈妈"可能不是妈妈；外公房间锁着。
- **主题**：服从的代价、爱与控制的边界、"好孩子"这个标签本身就是恐怖；隐私与边界被一点点剥夺。

## 三、核心玩法循环

### 1. 主线：写作业
- 每天 6 道难度递增的数学题（小游戏形式作答）。
- 【用户】玩家可以自己写以降低风险；不会的题必须外出找答案抄。
- 【建议】难度分布：前 2 题能自己写；中间 2 题可自写但很慢或外出找答案；后 2 题几乎必须外出。但"全靠自己"路线必须真的可行（难但不卡死）。
- 【建议】答错 = 重做 + 妈妈怒气上升，而不是直接失败。

### 2. 卧室：伪安全屋
- 妈妈定时**查岗**：必须坐书桌前、台灯开、课本打开、无违禁品、回答正确。
- 门后贴《家规》，有真有假。
- 卧室内要有小事件（台灯闪烁、衣柜异响、锁门、窗外），避免"不外出"路线无聊。

### 3. 外出：冒险与收益
- 趁妈妈忙碌的窗口外出（约 2~3 分钟），找答案、线索、道具。
- 靠声音判断妈妈位置，躲柜子/床底、静步、扔物品声东击西。
- 外出越多，**作弊值**越高，夜晚越危险。
- 【建议】节奏：开局 0 次外出（教学）→ 中段 2~3 次（目标明确）→ 末段 1 次大型高风险。
- 卧室与外出的平衡：**卧室待久了不行（查岗/怒气上升），外出待久了更不行（超时回不去=违规）**，双向倒计时，迫使玩家往返权衡。

### 4. 夜晚：外出的代价
- 只有外出过才进入夜晚。
- 规则全面变化：灯必须关、不能出声、不能睡着。
- 妈妈变成黑暗中的听觉怪物，靠呼吸声、床板响动追踪。
- 玩家用白天道具（耳塞、手电、护身符）撑到天亮；难度由作弊值决定。

### 5. 怒气系统（连接规则与怪物）
- 怒气 0~100，是核心状态量。
- 增加：违规、超时、被发现外出、作弊物证暴露、锁门。
- 减少：正确应答、完成题目、快速合规。
- 阈值：0~30 正常；30~60 查岗频繁、问话变怪；60~90 脸变形、脚步变重、门外徘徊；90+ 追逐。
- 妈妈的表情和声音必须能"读出"怒气，保证公平。

## 四、规则系统

### 1. 规则的四种类型
| 类型 | 说明 | 例子 |
|---|---|---|
| 真规则·显性 | 直接可验证，违反必罚 | 妈妈敲门必须答"在写作业" |
| 真规则·隐性 | 写得含糊，需事件才懂 | "听到爸爸的声音，不要回应" |
| 假规则 | 遵守反而有害 | "妈妈永远不会对你发火" |
| 条件规则 | 特定时间/状态生效 | "21:00 后不要开灯" |

### 2. 初始《家规》示例
1. 妈妈敲门，必须回答"在写作业"。
2. 妈妈在身后时，不要回头。
3. 作业必须在晚上 9 点前写完。
4. 不要开着门写作业。
5. 听到爸爸的声音，不要回应。（真规则，伏笔）
6. 妈妈永远不会对你发火。（假规则）

### 3. 设计原则
- 每条规则对应可观察的后果；规则之间制造张力。
- 假规则必须有**证伪线索**（日记、影子、遗物字条），不能凭空反转。
- 信息分层：开局 4~5 条，后续补充；单天规则总数 7~9 条为上限。
- 避免：规则太多太长、惩罚不透明、假规则无线索、怪物太强或太笨。

### 4. 【用户】动态规则：规则会随剧情和做题数量增、改、废
- **进度触发**：做完第 N 题，新增一条（稳定、可预期）。
- **剧情触发**：电话、遗物、照片等一次性强演出事件。
- **改/废**：旧规则被划掉、旁边手写新一条；或整张撕掉，表示保护失效。谁在改写保持悬念（后期可揭示是外公/爸爸留的"补丁"，衔接彩蛋线）。
- 【建议】**两层并存**：
  - 全局层：门后《家规》/笔记，长期有效，可随时查阅，会增改废。
  - 临时层：紧急纸条，事件时强制出现，原规则被血色覆盖，只剩一件事（≤6 字，如"别回头"）；事件结束血迹褪去，原规则仍有效。
  - 首次强制弹出（教学），之后音效提示 + 按键查看，妈妈开口时纸条在视野边缘抖动。
  - 掏纸条时视野被遮挡、不能移动——牺牲对身后的观察，与"别回头"天然呼应。
- 规则更新音效（写笔记声）：只用于重大变化，一天不超过 3~4 次，形成条件反射。

## 五、怪物设计：妈妈

### 设计卡
| 项目 | 内容 |
|---|---|
| 感知 | 听觉（脚步、碰撞、开门）+ 状态检查（查岗） |
| 目标 | 让你"合规"，不合规就"纠正" |
| 弱点 | 对规则内行为无反应；怕你装乖 |
| 破绽 | 位置矛盾（明明在厨房却站你身后）、笑容不对称、重复同一句话 |
| 惩罚 | 怒气满→追逐→被抓失败 |
| 应对 | 躲藏、静步、伪装状态、声东击西 |

### 双形态
- **A 日常妈妈（查岗）**：厨房活动→走向卧室→敲门→等回答→开门检查→离开。可预测，玩家靠观察时间规律。
- **B 异常妈妈（追逐/夜晚）**：只靠听觉，Investigate→Search→Return，可被欺骗。

### 追逐设计
- 短而强（30~60 秒）；目标是"逃回卧室并恢复合规"；回到书桌+答对，妈妈恢复正常（呼应伪安全屋）；不要无敌怪。
- 追逐是违规的后果，不是主玩法。

### 导演系统
- 查岗由时间表调度，而不是纯 AI 自由行动，更利于节奏控制。

## 六、【用户】关键剧情点与机制

### 1. 电话事件（中段高潮）
流程：
1. 外出探索时，卧室电话响起，玩家被迫赶回。
2. 接听亲戚电话：得知父母出去旅游了 → "那家里这个人是谁？"
3. 妈妈的声音和脚步从背后响起，就在背后。
4. 出现规则更新音效（写笔记声），同时妈妈发问。
5. 玩家需在短时间内：回答问题搪塞妈妈 + 看规则"别回头"，才能度过。

【建议】
- 采用**方案 A（只是怀疑）**：电话不揭示答案，真相留给遗物/日记/外公线索，保住结局 2 的分量。电话里加一句不对劲的细节（如"你妈让我别告诉你"），内容越日常越惊悚。
- 阅读窗口 8~12 秒；妈妈问话分两段，第二次追问才判定惩罚。
- 回答选项要"可推理"：顺从/搪塞正确；"你不是我妈"（拆穿）和沉默为错误——让玩家想选错的那个。
- "别回头"：诱导玩家回头（熟悉的声音、反光里的影子）；回头惩罚严厉但非即死，给一次后悔机会。
- 触发时机受控：只在相对安全区域触发，避免与躲藏/追逐冲突；只触发一次。
- 好孩子路线（不外出）不触发此事件，或电话响了但家规要求不接。
- 建议把它定为**第一天的核心剧情高潮**，并作为灰盒阶段第一个垂直切片。

### 2. 锁门机制
- 【用户】玩家可以锁门；妈妈会敲门，但只容忍固定次数/时间，这是给玩家恢复卧室规则的缓冲；一直锁门不回答，会触发恐怖行为：妈妈的头出现在窗外，脖子伸进来。
- 【建议】
  - 敲门分五阶段：轻敲温和→变重→语气失真、节奏过于整齐→**突然安静**（最可怕）→窗外异响、头伸入。
  - 缓冲时间 = 合规动作所需时间 + 2~3 秒余量；已合规可提前开门，奖励怒气小降。
  - 锁门要有成本：每次锁门怒气 +N；外出时无法锁；规则文本中可有"不要锁门"的条件规则；每天次数有限，防止当成暂停键。
  - 窗户提前铺垫（几层楼、窗帘飘动、怪影子）；窗户也有规则（如窗帘必须拉上）；头伸入后给玩家 5~8 秒反应，开门并回答则妈妈瞬间恢复并出现在门口。
  - 完整版恐怖一天最多一次，后续用轻量版（窗外影子、敲窗声）防止脱敏。
  - 锁门不算外出，不影响结局 1 判定。

### 3. 安全手段逐步失效
- 【用户】锁门、锁窗等行为随游戏进行越来越不能用：后半段锁门不再敲门，直接撞开、锁坏；日记本的锁也会被妈妈暴力破坏，象征掌控欲升级、玩家丧失安全感。
- 【建议】
  - 分阶段并有预告：前期正常→中期（敲门减少、锁上出现划痕）→后期（直接撞门，锁被破坏，不可再锁）。
  - 失效要**改变玩法**：从"补救"变为"预防"，必须提前保持合规；门坏后门缝透光，视觉提醒没有安全感。
  - 失效由**进度/天数**触发，不依赖外出——好孩子路线里玩家也会看着边界消失却继续听话（点题）。
  - 伪装在逐步崩坏：前期她还在装，后期懒得装了，顺理成章让第二天更暴力。
  - 克制：只做锁门、锁窗、日记三项。

### 4. 日记（最终为纯叙事版）
演变过程：存档+线索+选择写入（太复杂）→ 仅存档（仍不对）→ **最终：纯叙事日记本**。

- 【用户】只是一个单纯的日记本，记录玩家看见了什么、发生了什么、想什么，像小孩真会写的内容（如"今天妈妈很奇怪"），玩家可阅读。
- 【建议】
  - 定位：孩子视角的事件记录，游戏自动写入，玩家只读，无系统功能。
  - 写作：像真孩子（短句、口语、偶尔错别字、"今天"开头），越平淡越恐怖（"今天妈妈煮了我最爱吃的菜。可是她没有吃。"）。
  - 触发：事件后下次翻开日记时出现 1~2 句固定文本；关键选择（抄答案/自己写）可有两个版本。
  - 示例：
    - 第一次查岗："妈妈今天又来看我写作业。她站在门口，一动不动，好久。"
    - 抄答案："我偷偷看了答案。我好怕，可是妈妈夸我了。"
    - 亲戚电话："姨妈说爸爸妈妈去旅游了。那今天给我做饭的人，是谁呢？"
    - 锁门："我把门锁了。外面很安静，安静得不对。"
  - 剧情演变：前期字迹工整→中期出现**不是你写的一行字**（"我最爱妈妈"）→后期锁被撬烂、红笔批注"这样写不乖"、整页被撕/改写→好孩子路线内容越来越空洞，全是"今天也很乖"。
  - 阅读时视野被占用，沿用"别回头"的压力逻辑；关键线索只在日记中出现一次，奖励爱读的玩家。
  - 存档另行处理（每题自动存档即可）。
  - 毁坏前须预警（如妈妈说"你的日记本我看看"）。

## 七、三个结局（【用户】设计）

### 流程
```
第一天（写作业）
 ├─ 全靠自己、不外出 → 无夜晚，直接进入第二天
 └─ 外出/抄答案 → 夜晚 → 结局 2 或 3，或失败

第二天（题目更难 + 1~2 条新规则，场景不变）
 ├─ 连续两天都不外出 → 结局 1：好孩子
 └─ 外出/抄答案 → 夜晚 → 结局 2 或 3，或失败
```

### 结局表
| 结局 | 条件 | 内涵 |
|---|---|---|
| **1. 好孩子**（坏结局） | 两天都全靠自己做对所有题，从不外出 | 活成了家里人期盼的样子。**标题此时才出现**，最听话=最坏结局 |
| **2. 逃离**（正常结局） | 正常做题，外出收集线索，得知妈妈是假的，逃离家 | 识破真相，离开 |
| **3. 外公天降**（彩蛋结局） | 获得稀有道具，打开外公房门，柜子暗示外公是超人（维特鲁姆星人服饰，类似美漫《无敌少侠》摄政王形象），打电话后外公天降处理怪物 | 荒诞反转，规则被一拳打破 |

失败机制【建议】：被抓则回到当天开头，保留已获线索。

### 各结局的补充建议
- **结局 1**：第一天必须能安全走通；第一天结束给微妙暗示（妈妈笑容更"标准"、墙上多一张奖状）；第二天结束镜头拉远，房间成了"成功人士"样子，标题此时出现。"全对"可放宽为"无需外出完成 6 题"。第二天要有新规则，让玩家产生"这次必须外出"的动机。
- **结局 2**：需明确"得知"的条件——外出至少 N 次 + 收集关键线索（遗物/日记/照片）拼成证据链；夜晚面对妈妈时做出选择（开门离开）。
- **结局 3**：充分铺垫（外公照片、衣柜披风、奖章、剪报）；多线索拼接（披风碎片、钥匙藏在违规才会去的地方、电话号码分散在 3 处）；明确标注为彩蛋结局（存档标"？？？"）；做成固定演出（过场），不做复杂玩法，避免破坏恐怖基调。
- **核心选择**：不外出=安全=变成好孩子；外出=危险=看见真相。玩家的选择本身就是主题，宣传中应突出。

## 八、一天的时间轴（第一天参考）

| 幕 | 时间 | 内容 |
|---|---|---|
| 一 放学回家 | 18:00–19:00 | 进门、回应妈妈（选项式对话）、学家规、教学式查岗（失败不惩罚）、发作业 |
| 二 做题与首次外出 | 19:00–20:00 | 第 1~2 题自己写；第 3 题卡住→首次外出拿答案→躲避→抄写，作弊值+1 |
| 三 压力升级 | 20:00–21:00 | 查岗变频，问话变怪；第二次外出（父母房/储物间）发现爸爸遗物；电话事件、"背后的妈妈"、假妈妈暴露；中期追逐 |
| 四 夜晚 | 21:00–天亮 | 关灯、不出声、不睡；黑暗听觉怪物；道具生存；难度由作弊值决定 |

体验曲线：熟悉压抑→紧张试探→怀疑恐慌→窒息生存→反转余味。

第二天：场景不变，题目更难，新增 1~2 条规则，安全手段进一步失效（撞门、日记被毁），妈妈伪装更少。

## 九、核心爆点（宣传/记忆点）

1. **好孩子结局**：最听话=最坏结局，延迟出现的标题。
2. **玩家的选择即主题**：服从还是反抗，由操作回答而非旁白。
3. **动态规则 + 血红纸条"别回头"**：视觉符号，可做 LOGO/宣传图。
4. **"背后的妈妈"事件**：电话→真相怀疑→背后脚步→搪塞+不回头。
5. **窗外伸脖子的头**：伪安全屋被撕开。
6. **安全手段被收回**：撞门、撕日记、红笔批注。
7. **外公超人**：荒诞反转，截图/录屏传播点。
8. **家规文本、妈妈的笑**：适合短视频切片。

## 十、商业分析

### 优势
文化共鸣强（写作业、被盯、别人家的孩子）；规则怪谈/中式恐怖有稳定受众；传播性强；多结局重玩；单场景单怪物，体量可控；作品集覆盖 AI、规则系统、状态管理、多结局、氛围营造。

### 风险与对策
| 风险 | 对策 |
|---|---|
| 同类规则怪谈增多 | 以"选择即主题"和"好孩子结局"差异化 |
| 外公彩蛋破坏恐怖 | 充分铺垫，标注为彩蛋 |
| 不外出路线无聊 | 卧室内查岗、锁门、窗外、日记等事件保持紧张 |
| 题目难度因人而异 | 提示或难度选项，避免卡关 |
| 海外受众不理解文化 | 以中文市场为主，英文为次要 |
| 事件重复致脱敏 | 高光恐怖事件每天限一次，其余轻量版 |

### 发行建议
- 发售前 2~3 个月上线 Steam 页面，挂免费 Demo（第一天前半段）收愿望单。
- 投放渠道：B站、小红书、抖音恐怖游戏/规则怪谈创作者。

## 十一、技术实现思路（概要）

- 规则数据化：DataAsset/DataTable（RuleID、文本、真假、生效条件、违反事件、惩罚、证伪线索）。
- 统一 RuleManager 子系统：行为事件广播→匹配规则→触发惩罚/怒气变化。
- 妈妈 AI：Behavior Tree + Blackboard（AngerLevel、LastHeardLocation、PlayerCompliance、Mode）；AI Perception 听觉 + ReportNoiseEvent。
- 导演系统按时间表调度查岗与事件。
- 日夜流程状态机；对话为选项式限时选择，不做自由输入。
- 做题 UMG 小游戏，题库 DataTable。
- 氛围：音效优先，其次低照度 + Lumen。
- 美术提前规划窗户位置（外出、夜晚、窗外三处共用）。
- 开发顺序：灰盒（卧室+客厅，查岗+做题）→ 规则/外出/夜晚完整流程 → 美术音效演出 → 打磨测试+Steam 页面。
